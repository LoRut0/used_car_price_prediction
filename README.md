# Used Car Price Prediction

Интеллектуальная система для прогнозирования примерной стоимости подержанного автомобиля на основе его характеристик.

Проект разработан в рамках курсовой работы по дисциплине «Интеллектуальные системы».

Система использует методы машинного обучения для анализа данных об автомобилях и предсказания их ориентировочной рыночной стоимости в долларах США.

---

## Описание проекта

Цель проекта — разработать прототип интеллектуальной системы, которая позволяет пользователю ввести характеристики автомобиля и получить прогноз его примерной стоимости.

В системе реализованы:

- загрузка и обработка датасета с объявлениями о продаже автомобилей;
- очистка и подготовка данных;
- преобразование категориальных признаков;
- обучение модели машинного обучения;
- сохранение обученной модели;
- backend API на FastAPI;
- frontend-интерфейс на HTML, CSS и JavaScript;
- отправка данных с сайта на сервер;
- получение и отображение предсказанной цены автомобиля.

## Данные

В качестве исходных данных используется датасет объявлений о продаже подержанных автомобилей.

Датасет содержит следующие признаки:

- производитель автомобиля;
- модель;
- тип коробки передач;
- цвет;
- пробег;
- год выпуска;
- тип топлива;
- объём двигателя;
- тип кузова;
- состояние;
- тип привода;
- регион;
- количество фотографий;
- дополнительные опции автомобиля;
- цена автомобиля.

Целевой признак:

```text
price_usd
```

Именно значение `price_usd` модель должна научиться предсказывать.

---

## Особенности обработки данных

В процессе подготовки данных выполняются следующие действия:

1. Удаляются или не используются признаки, которые неудобны для ввода пользователем.
2. Пропущенные значения обрабатываются перед обучением модели.
3. Категориальные признаки кодируются с помощью `OneHotEncoder`.
4. Числовые признаки масштабируются или передаются в модель без кодирования.
5. Признаки `feature_*` объединяются в один числовой признак `features_sum`.
6. Столбец `up_counter` не используется при обучении модели.
7. Столбец `duration_listed` не используется как обычный пользовательский параметр, так как пользователь вводит данные автомобиля до публикации объявления.

Признаки `feature_0`, `feature_1`, ..., `feature_9` описывают наличие дополнительных опций автомобиля.  
Для удобства они объединяются в один параметр:

```text
features_count
```

Он показывает количество дополнительных опций у автомобиля.

Например:

```text
feature_0 = True
feature_1 = False
feature_2 = True
feature_3 = True
```

Тогда:

```text
features_count = 3
```

## Обучение модели

Перед запуском backend необходимо обучить модель.

Для этого выполните команду из корневой папки проекта:

```bash
python src/train.py
```

После успешного обучения в папке `models/` должен появиться файл:

```text
models/used_car_price_model.joblib
```

Этот файл содержит обученную модель и все необходимые объекты предобработки данных.

---

## Проверка модели через консоль

Для проверки работы модели можно запустить тестовое предсказание:

```bash
python src/predict.py
```

Скрипт должен загрузить модель из файла:

```text
models/used_car_price_model.joblib
```

и вывести предсказанную стоимость автомобиля.

````
## Полный порядок запуска проекта

### 1. Перейти в папку проекта

```bash
````

## Принцип работы системы

Общая схема работы системы:

```text
Пользователь
    |
    v
Frontend HTML/CSS/JS
    |
    v
FastAPI backend
    |
    v
ML-модель
    |
    v
Предсказанная стоимость автомобиля
```

Frontend отвечает за ввод данных пользователем и отображение результата.

Backend отвечает за приём запроса, проверку данных, загрузку модели и возврат результата.

ML-модуль отвечает за обучение модели и выполнение предсказаний.
